# 🏥 Diabetes Readmission Predictor

This project predicts whether a **diabetic patient** will be readmitted within 30 days after hospital discharge.

## 🚀 Features
- Built with a **Tuned Gradient Boosting Classifier**
- Interactive UI built using **Streamlit**
- Predicts risk of readmission with a stable probability threshold
- Clean, hospital-grade theme with real-time prediction feedback

## 🧠 Tech Stack
- Python
- Streamlit
- scikit-learn
- imbalanced-learn
- joblib
- pandas, numpy
